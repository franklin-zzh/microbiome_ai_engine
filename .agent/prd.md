# 极简付费点播系统(VOD) MVP方案设计
### 面向品牌引流与快速交付的系统架构及业务确认备忘录

为了在最短的周期内搭建起一套具备品牌质感、能够承接官网流量、并闭环完成“付费观看”的系统，本方案基于 MVP（最小可行性产品）理念设计。摒弃大厂复杂的会员社区与多级分销逻辑，将核心聚焦在“极致顺畅的支付体验”与“基础的内容防盗防护”上。

---

## 一、 业务闭环与用户黄金路径

为了让引流效果最大化，用户从官网点击到完成观看的链路应当缩到最短：

```text
1. 官网外部链接引流 ──> 2. 精美单页试看/简介 ──> 3. 微信/支付宝扫码支付 ──> 4. 动态鉴权/解锁完整播放
```


- **前端展现形态**：可以是一个独立的二级域名网页（如 `video.yourbrand.com`），也可以作为 `iframe` 直接无缝内嵌在官网的某个版块内。界面采用纯黑或高级留白背景，突出教学视频的专业度与品牌质感。
    
- **未付费状态**：播放器允许试看固定时长（如前 3 分钟），试看结束后自动暂停并弹出高颜值的中断提示框：“解锁完整课程，助你掌握核心技术”。
    
- **付费后状态**：用户扫码支付成功，页面无缝刷新，播放器获得完整播放权限。
    

## 二、 极简技术架构设计（低成本、快速交付）

考虑到目前教学视频暂存于钉盘，本方案推荐将其迁移至**阿里云 OSS（对象存储）**。不采用复杂的阿里云点播（VOD）服务，以省去繁琐的媒体转码与高昂的系统占用费。通过 OSS 配合后端轻量控制，即可达成“防盗”与“极速上线”的平衡。

### 技术栈推荐

- **前端**：HTML5 原生 + Tailwind CSS / React (单页应用) + DPlayer / Aliplayer（开源成熟的视频播放器，天生支持试看控时）。
    
- **后端**：Node.js (Express) 或 Java (Spring Boot) 轻量级服务，仅需 2 张核心表（用户激活凭证表、订单表）。
    
- **存储**：阿里云 OSS (私有 Bucket) + 阿里云 CDN 加速（保障公网播放丝滑不卡顿）。
    

### 核心安全防盗机制：OSS 临时 URL 签名鉴权

1. 将视频上传至阿里云 OSS **私有 Bucket**（外部人直接复制 URL 链接无法打开，提示无权限）。
    
2. 当后端确认该用户已完成付费后，利用阿里云 SDK 动态生成一个**带时效性的签名 URL**（例如：有效时间 10 分钟 `?Expires=16900000&Signature=xxxx`）。
    
3. 前端播放器拿着这个临时 URL 进行切片或直接播放。即使用户通过浏览器开发者工具抓包拿到了视频链接，该链接在 10 分钟后也会彻底失效，无法被二次传播或分享给他人下载。
    

## 三、 亟需与运营、业务方确认的 5 大核心细节

技术方案落地非常快，但在大厂的实际产品经验中，卡住项目上线进度的往往是法务、资质、业务策略等合规风险。请务必在开发前与运营/业务负责人（如张总、潘总）确认以下细节：

|**确认事项**|**潜在影响/风险**|**产品经理建议方案**|
|---|---|---|
|**1. 支付收款资质**<br><br>  <br><br>_(高优先级)_|微信/支付宝官方支付 API 申请必须要求企业营业执照，且需要审核 3-7 个工作日。如果没有企业商户号，代码写完也无法线上收款。|优先确认公司是否已有现成的“微信支付商户平台”或“支付宝商家中心”账号。若无，立即安排行政/运营提交资料申请。|
|**2. 账户与鉴权体系**<br><br>  <br><br>_(技术关联)_|传统的“手机号+短信验证码”注册体验重，且每条短信有成本；“匿名浏览器缓存”体验好，但用户换了手机或清理浏览器缓存后，已购买的权限会丢失，引发客诉。|微信扫码快捷登录/购买。若网页内嵌于微信生态，直接用服务号静默授权；若是 PC 端网页，采用微信扫码登录，既能留存用户微信号，体验又极顺畅。|
|**3. 计费与产品形态**<br><br>  <br><br>_(运营关联)_|是采用“单视频付费解锁”（如：29元解锁本集），还是“全站会员制”（如：99元包年看完所有教学视频）？这直接决定了后台数据库结构的设计。|由于处于品牌引流和 MVP 试水阶段，建议采用**单视频单次购买解锁**（或者打包一个大总集），逻辑最简单，开发周期最短。|
|**4. 域名与ICP备案**<br><br>  <br><br>_(合规风险)_|不管是阿里云 CDN 分发视频，还是对接微信/支付宝支付，都强制要求播放页面的域名必须拥有国内合规的 ICP 备案。未备案域名无法上线。|直接在公司现有的已备案的主域名下，**开辟一个二级域名**（如 `video.yourcompany.com`），完美避开重新备案的 20 天等待期。|
|**5. 售后与观看凭证有效期**<br><br>  <br><br>_(法务/客诉)_|用户付完钱后，是“永久可看”还是“30天内有效”？视频是否允许退款？如果没有在购买页清晰声明，极易引起客诉。|**永久观看**。本商品为数字内容，购买后暂不支持退款，做好法务免责。并在支付弹窗下方标注一行小字说明（如：“购买后凭当前账号可不限次数永久观看，本商品为数字内容，购买后暂不支持退款”）。|
