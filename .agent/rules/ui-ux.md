# UI/UX 表现与付费墙控制规则 (.agent/rules/ui-ux.md)

## 1. 前端展现形态与视觉规范
* **部署形态**：支持作为一个独立的二级域名网页（如 `video.yourbrand.com`）运行，或作为 `iframe` 直接无缝内嵌在官网的某个版块内。
* **视觉风格**：界面设计必须采用纯黑或高级留白背景，界面元素保持 Organic Minimalism（有机极简）风格，极力突出教学视频的专业度与品牌质感[cite: 1]。

## 2. 播放器状态控制逻辑（核心业务）
前端集成播放器（如 DPlayer）时，必须通过代码严格区分以下两种状态[cite: 1]：

### ❌ 未付费状态 (Unpaid State)
* **试看控时**：播放器仅允许试看固定时长（严格限制为 **前 3 分钟**）[cite: 1]。
* **中断拦截**：试看结束（`currentTime >= 180`）后，代码必须立即触发自动暂停（`player.pause()`）[cite: 1]。
* **UI 联动**：在播放器上方无缝覆盖一层高颜值的模糊中断提示框，文案统一为：**“解锁完整课程，助你掌握核心技术”**，并直接内嵌或弹出微信/支付宝的支付二维码[cite: 1]。

###  付费后状态 (Paid State)
* **无缝刷新**：用户扫码支付成功后，通过 WebSocket 或轮询触发页面无缝刷新[cite: 1]。
* **权限解锁**：播放器重新初始化，获得后端分发的完整无限制播放权限[cite: 1]。
