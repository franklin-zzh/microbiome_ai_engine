# 安全合规与防盗链硬核规则 (.agent/rules/security.md)

## 1. 核心安全防盗机制：OSS 临时 URL 签名鉴权
当编写任何涉及视频资源上传、分发、读取的接口时，后端与运维必须无条件执行以下三步物理防御：

1. **绝对隔离（私有桶）**：
   * 所有教学视频源文件必须上传至阿里云 OSS **私有 Bucket**[cite: 2]。
   * 桶权限（ACL）必须锁死为 `private`。任何外部人员直接复制原始 URL 链接必须无法打开，由阿里云底层直接提示无权限[cite: 2]。
2. **后端动态鉴权（临时签名）**：
   * 当后端收到前端的播放请求时，必须先校验 `user_video_permissions` 表，确认该用户已完成付费[cite: 1, 2]。
   * 确认付费后，利用阿里云 SDK 动态生成一个**带有时效性的签名 URL**[cite: 2]。
   * **时效红线**：有效时间严格限制为 **10 分钟**（参数必须包含且不限于 `?Expires=xxx&Signature=xxxx`）[cite: 2]。
3. **前端切片与动态失效**：
   * 前端播放器拿着这个临时 URL 进行切片或直接播放[cite: 2]。
   * 即使用户通过浏览器开发者工具（F12）抓包截获了该视频链接，该链接在 10 分钟后也必须彻底失效，无法被二次传播或分享给他人下载[cite: 2]。

## 2. 研发红线
* 严禁在接口返回值中透传任何未带签名的 OSS 原始文件路径。
* 签名计算过程必须全部在后端完成，严禁将阿里云 AccessKey 暴露给前端。
